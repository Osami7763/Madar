# مدار — موقع فضاء تفاعلي

موقع عربي تعليمي عن الفضاء، يضم دليلًا مبسطًا للكواكب والنجوم والمجرات والظواهر الكونية، مع **محاكي تفاعلي للنظام الشمسي** يعمل بالكامل داخل المتصفح.

## ما يتضمنه الموقع

- واجهة عربية متجاوبة باتجاه RTL.
- محاكي مدارات مرئي مبني على Canvas.
- تشغيل/إيقاف الحركة، تغيير سرعة الزمن، إظهار/إخفاء المدارات والأسماء.
- سحب المشهد والتكبير والتصغير وإعادة ضبط العرض.
- بطاقات للكواكب الثمانية مع معلومات المسافة وطول السنة وحقائق سريعة.
- بحث فوري في الكواكب وموضوعات الكون.
- مقالات قصيرة عن الثقوب السوداء والنجوم والمجرات والأقمار والكويكبات والمذنبات والظواهر الكونية.
- أصول مرئية محلية داخل `assets/`، لذلك لا يعتمد الموقع على روابط صور خارجية.

## التشغيل محليًا

لا يحتاج المشروع إلى تثبيت حزم أو خادم؛ يمكن فتح `index.html` مباشرة في المتصفح.

ولتشغيله عبر خادم محلي:

```bash
python3 -m http.server 8080
```

ثم افتح:

```text
http://localhost:8080
```

## النشر عبر GitHub Pages

1. افتح **Settings → Pages** في المستودع.
2. اختر **Deploy from a branch**.
3. اختر الفرع `main` والمجلد `/ (root)`.
4. احفظ الإعداد وانتظر رابط النشر.

## بنية الملفات

- `index.html` — الصفحة والمحتوى.
- `style.css` — التصميم والتجاوب.
- `script.js` — المحاكي والبحث والتفاعلات.
- `assets/` — الصور والأيقونة المحلية.
- `manus-routes.json` — تعريف المسار الرئيسي للموقع.

الخطوط العربية تُحمّل من Google Fonts عند توفر الإنترنت، مع بدائل محلية مناسبة عند عدم توفره.

## ملاحظة تعليمية

الحركة والمدارات في المحاكي تمثيل بصري مبسط للتعلم والاستكشاف، وليست مقياسًا علميًا دقيقًا للأحجام أو المسافات أو السرعات المدارية.

## محتوى الموقع

- شاشة ترحيب بصورة شعار **ثانوية نجد** تظهر عند فتح الموقع، مع زر للدخول مباشرة.
- قسم تعريفي يشرح نشأة الكون والنجوم والمجرات والمادة المظلمة والحياة وطرق الاستكشاف.
- قسم لرواد الفضاء يضم الاسم والجنسية وتاريخ الرحلة والمهمة والمدة وسبب الرحلة، مع صور محلية.
- بطاقة تعريف بالمشروع تتضمن إشراف رائد النشاط ومدير المدرسة والطلاب القائمين عليه.


## المصادر والحقوق

يوجد في الموقع قسم للمراجع، وتظهر وصلة المصدر أسفل بطاقة كل رائد فضاء. حقوق المشروع محفوظة لـ **ثانوية نجد**.
