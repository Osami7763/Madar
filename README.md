# مدار — موقع فضاء تفاعلي

نسخة ثابتة مبنية باستخدام **HTML وCSS وJavaScript فقط**. لا تحتاج إلى Node.js أو npm أو Vite أو أي خادم محلي.

## التشغيل على جهازك
1. نزّل المستودع كاملًا واستخرج الملفات مع الحفاظ على مجلد `assets`.
2. افتح `index.html` مباشرةً في المتصفح.
3. تأكد من السماح لـJavaScript في المتصفح؛ فهو يشغّل المحاكي والأزرار والبحث.

الملفات الرئيسية:
- `index.html` — الصفحة ومحتواها.
- `style.css` — التصميم والتنسيق المتجاوب.
- `script.js` — المحاكي والبحث والتفاعلات.
- `assets/` — الصور والأيقونة المحلية.

الخطوط الاختيارية تُحمّل من Google Fonts عند توفر الإنترنت؛ تبقى الصفحة منسّقة عند عدم توفره باستخدام الخطوط البديلة.
