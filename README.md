# مشروع مدار

موقع تعليمي عن الفضاء من إعداد طلاب ثانوية نجد. يجمع الموقع بين معلومات مبسطة عن الكون ومحاكي تفاعلي للنظام الشمسي.

## الملفات المهمة

- `index.html` الصفحة الرئيسية ومحتوى الأقسام.
- `style.css` ألوان الصفحة وتنسيقها على الجوال والكمبيوتر.
- `script.js` المحاكي والبحث وتفاعل الأزرار.
- `astronauts.js` بيانات رواد الفضاء وبطاقاتهم.
- `assets/` الصور المستخدمة في الصفحة.

## التشغيل

افتح ملف `index.html` في المتصفح. يمكن أيضًا تشغيله من خلال أي خادم محلي بسيط.

## ملاحظات

المحاكي رسم تعليمي تقريبي، وليس مقياسًا حقيقيًا للمسافات أو أحجام الكواكب. المعلومات مأخوذة من صفحات ناسا ووكالة الفضاء الأوروبية ووكالة الفضاء السعودية ومصادر تعريفية أخرى، ويمكن فتح المصدر من أسفل كل بطاقة.

حقوق المشروع محفوظة لثانوية نجد.
