# مدار — الشيفرة المصدرية

نسخة مصدرية قابلة للتشغيل من الموقع، تشمل صفحة HTML والتنسيقات وJavaScript والأيقونة والصورتين المستخدمتين في الموقع. نُقلت الصور إلى `public/assets/` وجُعلت مراجعها محلية كي تعمل الحزمة خارج معاينة Manus.

## المتطلبات
- Node.js 20 أو أحدث
- npm

## التشغيل محليًا
```bash
npm install
npm run dev
```
افتح العنوان الذي يعرضه Vite (غالبًا `http://localhost:3000`).

## بناء نسخة الإنتاج
```bash
npm run build
npm run preview
```

الملفات الأساسية: `index.html`، `src/style.css`، `src/main.js`. الخطوط العربية تُحمّل من Google Fonts مع بدائل محلية عند عدم توفر الاتصال. `app.config.ts` إعداد اختياري خاص بعلامة مشروع Manus.
